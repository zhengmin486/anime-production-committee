# 当前进度与方向（2026-11-22）

> 本文件区分「规则讨论已确认」「契约已落地」「玩法已实现」。三者不可混为一谈。议题评论是规则决策记录，代码与真实 WASM 验收才代表功能实现。

## 一句话现状

V1.0 的核心方向和多个跨系统规则已形成明确口径；M1 的 C++/WASM 核心已实现周制、五阶段和公司终局，但前端主流程仍需完成 v3 接入。M2 的企划、委员会、员工与供应商等规则正在由 #6/#7 承接；部分新增状态和动作已进入契约，相关玩法尚不能据此视为实现。作品历史、成长、长期结局与事件规则已讨论出主要边界，仍需按分工实现和集成。

## 1. 规则方向已确认

### 总体循环
- 十年经营周期，共 520 周；以周为基本时间步。
- 公司一次只制作一部作品；项目之间仍需支付工资与运营成本。
- 五阶段制作；阶段开始配置，阶段内自动推进，阶段间重新配置。
- 玩家做阶段性经营决策，不进行逐周重复微操。
- 公司终局包括破产、主动结束和十年期满；项目交付与公司终局分离。

### 企划与合作
- 市场每次刷新固定四个企划，至少两个可立即承接；锁定项目仍展示解锁条件。
- IP 上门占用市场四槽之一，不增加槽位。
- 自定原创企划、员工提案使用独立槽位，不占市场四槽；员工提案只展示一次，未采纳即消失。
- 玩家主动发起原创需要企划能力员工；员工提案没有该人员门槛。两者均有固定前期开发费用。
- 原创必须采用委员会投资，公司承担 10%–100% 投资；其他投资方补足剩余份额。
- 承制与委员会投资的收益结构不同；承制无商业分成，委员会按渠道结算。

### 制作、人员与事件
- 五阶段：script、storyboard、key_animation、animation_check、postproduction。
- 阶段配置首锁定，事件可按具体规则提供受控例外。
- 固定核心团队加项目临时招募；员工六项能力、天赋/潜力、经验成长、疲劳与士气。
- 只做离职风险预警，不做随机离职。
- 项目事件包含正面机会和负面异常；表现触发与随机触发结合，每周最多一个，同一时间最多一个待处理事件。
- 事件效果可即时、阶段或项目持续；不跨项目永久生效，不修改合同目标，不绕过财务、员工、供应商和终局规则。

### 作品与长期反馈
- 制作质量与商业成绩独立；质量采用综合分和 S/A/B/C/D 档。
- 商业收入按渠道计算；BD 为基础渠道，公司至少获得 BD 收益 50%，其他渠道由立项时固定的委员会成员开放。
- 市场热度为大热/高/中/低四档，影响市场企划、IP 上门概率和非合同商业收益，不影响合同收益。
- 公司声望初始 100，具有数值和等级，不自然衰减；影响企划、委托、招募、供应商、原创融资规模和媒体曝光，不直接影响制作能力或委员会压力。
- 作品履历、系列化、续作商业基础、结局综合评价和特殊评价均有明确方向。
- 竞争公司只在作品结算时参与比较；不模拟日常经营。

## 2. 契约层已落地

- M0 的 v3 状态、动作、状态机、财务分类与手算样例已冻结。
- M1 已在 C++/WASM 实现部分 V3 周制、五阶段和公司终局行为，核心测试有真实 WASM 与原生证据；这不代表完整 V3 玩法或前端主流程已完成。V1.0 初始声望目标为 100，当前 M1 参数仍为 0，需在后续核心参数同步时调整，不能将当前实现值误认为设计定案。
- origin、style、min_reputation、员工招募抽卡的 scout / targeted_scout 与 scout_pity 已进入契约。
- 自定企划与员工提案槽位、原创企划创建/采纳/拒绝/丢弃、电视播出服务购买等动作已进入契约。
- development、distribution 成本类别、委员会成员/渠道结构、分渠道对账、作品档次和历史成绩解锁条件已进入契约。
- 新增字段遵循可选字段与缺省语义纪律：核心行为实现前，旧 M1 v3 状态仍应合法；契约存在不代表对应动作已实现。

## 4. 仍需执行阶段细化的内容

以下不是重新讨论总体方向的理由，交模块负责人给出推荐值、理由、影响面和验收方式：

- 市场热度的更新周期、档位转换概率、非合同收益系数、企划/IP 上门生成权重。
- 声望等级阈值与称号，以及各影响面的概率/系数。
- 作品五阶段权重模板、S/A/B/C/D 分数线、企划适配度算法和重大事故评价影响。
- 各商业渠道收入公式、渠道潜力生成、股东分账比例与电视服务成本/宣传效果。
- 原创企划前期开发费、员工提案周期概率、市场刷新权重。
- 事件内容清单、触发阈值/概率/优先级/冷却、处理成本与效果。
- 成长、疲劳、士气、招募、供应商、续作和结局的具体参数。
- 所有待定数值集中在核心规则配置中，需附来源；不得在前端另写一套公式。

## 5. 集成审查重点

总体规则不再凭空增加系统，后续重点是检查跨系统关系是否一致：

1. **公司账与项目账**：现金只扣一次；合同预算、投资本金、前期开发费、渠道收入、分账和项目成本各有唯一口径。
2. **市场、声望与热度**：声望决定机会档次/准入，热度影响题材供给和非合同收益；两者不能误用于合同收益或员工提案触发。
3. **企划来源与合作模式**：市场、IP 上门、自定原创、员工提案的槽位与生命周期不同；原创必须委员会投资。
4. **制作阶段与事件**：事件只在合法项目状态检查；不能追溯已结算阶段，不能绕过阶段配置锁或合同限制。
5. **质量与商业**：制作质量、作品档次、商业表现和公司声望相互关联但不可混为一个指标。
6. **长期履历与结局**：作品快照、续作关联、团队成长和十年综合结局必须在存档中形成闭环。
