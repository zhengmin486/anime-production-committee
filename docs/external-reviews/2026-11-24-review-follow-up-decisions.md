# 独立游戏设计评审后续待定事项

> 本文记录对《独立游戏设计评审报告》的逐条讨论结果，以及讨论中产生、尚未进入正式决策的补充想法。本文不是正式决策登记册，不自动修改现有规则、契约或里程碑。

## 1. 制作与市场的中途反馈（报告 P0-1：边播边做）

**讨论结论：认可长期方向，首版不实施。**

- 长期方向：播出反馈应成为真实的经营因素。未来版本可以研究观众反响、口碑、配信热度等反馈如何影响后续制作策略、资源投入、商业机会和作品经营。
- 首版范围：不引入逐集播出、边播边做、逐集市场反馈或分期收益结算；继续维持现有整部作品制作与交付结构。
- 后续研究重点：
  1. 播出反馈是否能改变玩家决策，而非只增加数值。
  2. 播出与制作如何衔接，是否允许播出期间继续制作。
  3. 反馈如何影响后续制作、商业合作和公司经营。
  4. 如何避免增加逐集排期和每周微操。
- 当前处理：不修改现有制作 DAG、整部交付规则及 M1–M7 里程碑。

## 2. 员工主要职业方向（讨论补充，待定）

朕明提出以下八个方向，作为员工主要职业方向的初步构想：

1. 作画
2. 演出
3. 脚本
4. 摄影
5. 监督
6. 音乐
7. 声优
8. 美术

**当前状态：作为待讨论方案记录，不视为正式冻结的职业体系。**

后续细化时需要区分：
- **职业方向**：员工主要从事的工作领域。
- **专业能力**：员工在该方向上的具体能力与专长。
- **制作岗位**：员工在某部作品、某个制作阶段实际承担的职责。

补充边界：
- 作画与美术分别保留，不因都涉及画面而合并。
- 演出与监督分别保留，前者偏向单集视听呈现，后者偏向整体创作把控与质量判断。
- 音乐、声优方向需允许内部员工与外部合作人员两种实现方式。
- 八个职业方向不与现有六个单集制作阶段强行一一对应；一个阶段可以由多个职业共同参与，一个职业也可能参与多个阶段。

后续仍需验证职业方向是否覆盖实际制作流程、是否需要补充或调整，以及职业方向与员工能力数值、工作项需求之间的映射方式。
