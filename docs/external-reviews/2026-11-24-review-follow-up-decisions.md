# 独立游戏设计评审后续待定事项

> 本文记录对《独立游戏设计评审报告》的逐条讨论结果，以及讨论中产生、尚未进入正式决策的补充想法。本文不是正式决策登记册，不自动修改现有规则、契约或里程碑。

## 1. 制作与市场的中途反馈（报告 P0-1：边播边做）

**讨论结论：认可长期方向，首版不实施。**

- 长期方向：播出反馈应成为真实的经营因素。未来版本可以研究观众反响、口碑、配信热度等反馈如何影响后续制作策略、资源投入、商业机会和作品经营。
- 首版范围：不引入逐集播出、边播边做、逐集市场反馈或分期收益结算；继续维持现有整部作品制作与交付结构。
- 后续研究重点：
  1. 播出反馈是否能改变玩家决策，而非只增加数值。
  2. 播出与制作如何衔接，是否允许播出期间继续制作。
  3. 反馈如何影响后续制作、商业合作和公司经营。
  4. 如何避免增加逐集排期和每周微操。
- 当前处理：不修改现有制作 DAG、整部交付规则及 M1–M7 里程碑。

## 2. 员工主要职业方向（讨论补充，待定）

朕明提出以下八个方向，作为员工主要职业方向的初步构想：

1. 作画
2. 演出
3. 脚本
4. 摄影
5. 监督
6. 音乐
7. 声优
8. 美术

**当前状态：八个基础职业已确认保留，具体职业与岗位映射见第 4 节。**

后续细化时需要区分：
- **职业方向**：员工主要从事的工作领域。
- **专业能力**：员工在该方向上的具体能力与专长。
- **制作岗位**：员工在某部作品、某个制作阶段实际承担的职责。

补充边界：
- 作画与美术分别保留，不因都涉及画面而合并。
- 演出与监督分别保留，前者偏向单集视听呈现，后者偏向整体创作把控与质量判断。
- 音乐、声优方向需允许内部员工与外部合作人员两种实现方式。
- 八个职业方向不与现有六个单集制作阶段强行一一对应；一个阶段可以由多个职业共同参与，一个职业也可能参与多个阶段。

后续仍需验证职业方向是否覆盖实际制作流程、是否需要补充或调整，以及职业方向与员工能力数值、工作项需求之间的映射方式。

## 3. 周决策密度与时间推进（报告 P0-2：半月回合或智能快进）

**初步讨论方向：优先研究增加每周可采取的有效行动，不先压缩时间步。**

用户补充意见：
- 可以考虑加速键，但这是后期公司规模扩大后的便利功能，不是解决前期节奏问题的首要手段。
- 前期以短篇 OVA 为主时，项目规模较小、经营操作相对频繁，玩家每周应该有更多可做的事情。
- 周决策稀疏问题更应该先从增加每周可采取的行动入手，而不是直接把 520 周改成 260 个半月回合。

当前分析：
- 报告指出大量周推进缺少有效决策，这一体验风险值得验证；但“改成半月制”只是解决方案之一，不应直接接受。
- 保留周作为基础时间单位，暂不改变工资、工期、疲劳、随机结算等时间口径。
- 重点研究每周行动空间：玩家每周可以做哪些经营、制作、人事、商务或项目管理操作；这些行动如何形成取舍，避免只是增加重复点击或无意义待办。
- 加速键或推进至下一关键节点可作为后期便利功能研究，随着公司和项目规模扩大再评估其必要性。
- 不预设每周必须塞满操作；目标是让玩家在需要介入时有值得做的事，而不是强迫每周完成固定数量的任务。

**当前状态：方向性意见已记录，尚未形成正式裁决。** 后续需要进一步梳理可增加的每周行动类型、行动次数/成本/机会成本，以及前期小规模经营与后期规模化经营的节奏差异。

## 4. 八个基础职业、岗位适配与职业转换（DISC-11）

**讨论结论：保留原设计的八个基础职业；职业与岗位分层；取消“跨界”适配档。**

### 4.1 职业与岗位的关系

- **职业**是员工的专业身份，保留八个基础职业：脚本、演出、作画、美术、摄影、音乐、声优、监督。
- **岗位**是员工在具体作品和工作项中承担的实际职责。
- 职业不等于岗位。员工可以承担非本职业主责的岗位，但专业适配程度不同。
- 不设置“跨界”第三档：职业与岗位专业匹配时为主责；不匹配但规则允许参与时为协力。
- 协力不是无条件胜任任何岗位。具体工作项是否允许某职业协力，仍由职业—岗位适配规则定义。

### 4.2 八职业与工作项映射

| 基础职业 | 主责工作项 | 协力工作项 | 说明 |
|---|---|---|---|
| 脚本 | `series_composition`、`script` | `episode_direction_plan` | 故事构成与脚本 |
| 演出 | `episode_direction_plan`、`storyboard` | `editing`、`animation_check` | 单集视听呈现与执行 |
| 作画 | `character_design`、`layout`、`key_animation`、`inbetween`、`animation_check` | `background` | 包含原画、中割与作画检查 |
| 美术 | `art_setting`、`background`、`color_design`、`art_check` | `layout` | 背景、美术设定与色彩 |
| 摄影 | `composite`、`editing`、`delivery_master` | `inbetween`、`sound_mix` | 视觉后期与成片输出 |
| 音乐 | `music`、`op_ed` | `sound_mix` | 独立音乐创作；允许外包音乐公司 |
| 声优 | `dubbing` | `op_ed` | 声音表演；允许项目制临时参演或外包事务所 |
| 监督 | 全片统筹把关；高阶协力 `storyboard`、`editing`、`dubbing` 配音指导 | 全流程卡壳救火与节奏把控 | 不与演出争夺普通制作岗位，特殊机制见下文 |

上述映射为当前确认的设计口径；工作项的具体配置、协力许可和数值仍需落入蓝图/员工规则并经过验证。

### 4.3 主责与协力适配

- 主责：职业与岗位专业匹配，工作效率按 100% 基准计算，正常发挥该岗位对应的专业质量贡献。
- 协力：职业与岗位不完全匹配但规则允许参与，工作效率暂按 60% 基准计算，主要用于推进进度；不因此获得该岗位的专业质量上限。
- 不设置 20% 跨界档，也不以“跨界”作为员工调度类别。
- 工作量效率、质量贡献、疲劳代价三轴独立计算。疲劳不由适配档位自动推导，具体倍率待数值标定。
- 协力人员的质量贡献不等同于效率百分比；不得简单将 60% 工作效率换算成 60% 质量。
- 适配规则必须明确哪些职业可以协力哪些岗位，不能默认所有职业都能参与所有工作项。

### 4.4 监督的三类独立特殊机制

监督不作为普通工作项产能职业处理，其价值通过独立机制体现：

1. **质量收敛（只托底，不压顶）**：仅压缩负向质量波动，不削弱正向波动。示例区间 `[-15%, +15%] → [-5%, +15%]` 仅作为标定示例，最终参数待模拟验证。
2. **质量上限影响（单向正向）**：依据监督的 `direction`、`planning` 能力及关键标签，在定调和高潮把关时提供正向评价上限加成；普通合格监督可为 +0%，高阶名监督示例为 +3%～+12%。具体计算与参数待标定，不设置低能力监督的负倍率惩罚。
3. **组织协调（衔接 DISC-13）**：
   - 普通人员接手已开始的工作项时，监督可依据 `management` 能力部分减免一次性磨合损失；减免比例待标定，示例为 20%～40%，且至少保留原损失的 60%，不得清零。
   - 监督本人切换项目时，完整触发 DISC-13 规定的团队层面一次性损失，不予减免。

三类机制分别结算，不相互替代；具体实现和数值进入后续标定。

### 4.5 六项通用 ability 与八职业分层

不为八个基础职业扩充底层 `ability`。职业映射与蓝图工作项的通用能力需求是两层配置。

当前确认的蓝图能力归属修正：
- `animation_check`：`direction` 改为 `drawing`。
- `editing`：`direction` 改为 `postproduction`。
- `storyboard`：保留 `direction`。
- `dubbing`、`music`、`op_ed`：保留 `postproduction`。

职业决定员工的专业身份及岗位适配；`ability` 描述工作项所需的通用能力。两者共同参与生产计算，但不可混为同一字段。

### 4.6 职业转换

**讨论结论：保留职业转换方向，但首版不实现复杂转职系统。**

- 员工初始职业在入职时确定。
- 员工通过实际参与相关工作积累经验与履历，具备长期转向其他职业的可能。
- 职业转换由玩家主动决定，不自动发生；原职业积累不清零。
- 职业转换不是普通岗位调动：岗位调动只改变当前承担的工作，职业转换则改变员工长期专业身份及后续主责适配关系。
- 监督转换应比普通职业转换更强调全片统筹、关键节点把关等实际履历，不能只凭能力数值达标。
- 首版先保留规则扩展空间，优先跑通八职业、岗位适配与员工成长；转换条件、成本、限制次数和具体实现留待后续验证。
