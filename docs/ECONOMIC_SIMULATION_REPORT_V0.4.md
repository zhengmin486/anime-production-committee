# 经济模拟报告 V0.4（动态工作量与阶段合格线首轮试跑）

> 历史资料说明：本文记录旧版 V2/V3 契约、旧五阶段制作模型或当时的研究建议，不代表当前目标玩法。现行决策以 [DECISION_LOG.md](DECISION_LOG.md) 为准：项目级公共制作 + 单集六阶段、工作项依赖并行、核心员工每周严格单项目分配、多项目并行及限时资金危机。本文中的旧阶段、资源分配和资金规则仅作为历史证据/旧实现迁移参考，不得直接作为新架构依据。


> 状态：已将五阶段工作量、动态阶段合格线、可选打磨、工作量波动与周产能接入可复现模拟器。每种策略运行 500 次。结果用于检查机制和暴露参数问题，不构成最终平衡结论。运行日期：2026-11-23。

## 1. 本轮变更

相较 V0.3，本轮不再用对数正态工期直接决定项目是否延期，而是根据每周实际完成的工作量推进五个制作阶段：

| 阶段 | 工作量占比 |
|---|---:|
| 脚本 | 10% |
| 分镜 | 15% |
| 原画 | 35% |
| 动画检查 | 25% |
| 后期 | 15% |

- 项目基础工作量使用现有数值提案：短篇 1800、OVA 1200、TV 6000、剧场版 8000；每个项目实际工作量按 12% 波动。
- 每个阶段的合格线独立抽样，范围为阶段工作量的 65%–80%。达到合格线即可进入下一阶段。
- 每阶段有 35% 概率选择额外打磨，打磨额外消耗该阶段基础工作量的 20%，并暂时增加 1.5 点质量。打磨概率和增量均为实验参数。
- 假设项目周产能为 110 工作量单位，并加入 12%随机波动。这个数值大致参考标准项目工作量/标准周期，但不是员工系统的最终产能。
- 合同标准周期是死线。委员会项目在原周期结束时仍未完成全部阶段，自动使用一次 20%延期；承制不延期。延期期间持续扣正常固定运营成本，压力按延期周数累计。
- 截止时未完成全部阶段，累计工作量达到总工作量 50%则低完成度交付，低于 50%则违约。50%为临时实验线，不是正式规则。

## 2. 运行设置

- 经营周期：520 周；每种策略 500 次，共 2000 次模拟。
- 固定 seed：`20261123`。
- 初始现金：5000 万日元；每周固定运营成本：68 万日元。
- 策略：全部承制、委员会固定 10%、委员会固定 50%、委员会固定 100%。
- 投资、合同预算入账、BD收入、成功奖励、违约扣罚沿用 V0.3 口径；非BD渠道收入关闭，制作工作量成本暂不计费。
- 运行命令：`python scripts/economic_simulator.py`。

## 3. 首轮结果

期末现金单位为百万日元。项目数量为每次 520 周模拟的平均值。

| 策略 | 破产率 | 期末现金中位数 | 正常交付均值 | 低完成度交付均值 | 违约均值 | 延期均值 |
|---|---:|---:|---:|---:|---:|---:|
| 全部承制 | 0.0% | 3125.15 | 15.756 | 1.092 | 0.604 | 0 |
| 委员会固定10% | 0.0% | 2542.65 | 16.714 | 0.398 | 0.590 | 0.738 |

其他观察值：承制平均最终质量 69.42，委员会10%为 69.44，委员会50%为 63.82。委员会100%多数情况下无法启动项目，破产主要来自长期无法承担下一个项目投资、同时持续支付固定运营成本。

## 4. 初步观察

1. 动态阶段推进已经替代随机工期占位模型。标准工作量与合同周期的比值、阶段合格线、可选打磨和周产能共同决定实际完工时间。
2. 委员会项目出现延期，承制项目没有延期，符合当前规则边界。当前委员会10%每次模拟平均延期约 0.74 个项目，委员会50%约 1.28 个项目。
3. 低完成度交付和违约均有发生。当前低完成度交付线为 50%，并非用户已确认的正式阈值；后续需要结合“只要仍有一定价值就交付”的设计继续校准。
4. 固定投资比例策略仍然过于僵硬。委员会100%在初始资金下无法持续开展项目，不能据此得出委员会路线不可行；真实玩家可以先承制积累现金并动态调整投资比例。
5. 现金结果仍显著偏高，主要因为工作量尚未产生工资、外包、加班等制作成本，且非BD渠道收入关闭。现阶段不能据此判断承制/委员会的实际盈利能力。

## 5. 本轮测试

- 自动化测试：6/6 通过。
- 覆盖评分档位、固定seed可复现、承制不延期、委员会延期次数边界、阶段合格线动态范围，以及低产能下延期触发。
- 模拟器无第三方 Python 依赖。

## 6. 尚未解决的问题

1. 110 工作量单位/周的统一产能是占位值。必须由员工模块提供核心员工、临时员工、岗位分配、疲劳、加班和外包的产能/成本契约替换。
2. 项目规模小/标准/大尚未接入；本轮每种项目类型只使用标准规模。
3. 阶段合格线 65%–80%、打磨概率 35%、额外工作量 20%、低交付线 50%、质量增益 1.5 都是待讨论的参数。
4. 当前阶段工作量完成后直接推进，尚未模拟返工、阶段间依赖、质量缺陷和返修。
5. 完成度与作品质量、商业表现、声望之间仍是简化关系；渠道分成、非BD收入和项目实际制作成本未完整接入。

**结论：** 模型已从“随机抽工期”升级为“按阶段工作量推进”，可作为后续员工产能与成本接入的基础。但本轮现金结论明显受到制作成本缺失影响，不应用于决定投资比例、违约扣罚或商业平衡。
