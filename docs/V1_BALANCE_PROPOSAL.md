# V1 数值基准提案（游戏性优先）

> 历史资料说明：本文记录旧版 V2/V3 契约、旧五阶段制作模型或当时的研究建议，不代表当前目标玩法。现行决策以 [DECISION_LOG.md](DECISION_LOG.md) 为准：项目级公共制作 + 单集六阶段、工作项依赖并行、核心员工每周严格单项目分配、多项目并行；资金规则当前按 DEC-FIN-002/003 直接破产处理，旧限时危机周机制仅为未来更新候选。本文中的旧阶段、资源分配和资金规则仅作为历史证据/旧实现迁移参考，不得直接作为新架构依据。


> 状态：初始平衡参考值，供各模块实现与首轮模拟使用；不是现实行业报价表，也不代表已经通过平衡测试。数值优先保证首局可玩、经营路线有差异、十年成长有空间，再结合业界资料校准数量级。
>
> 金额单位：日元。金额表中的“万”表示万日元。

## 1. 统一评分档位

**所有以 0–100 表示的评分等级，80 分及以上统一属于最高档，不再把 80–89 与 90–100 拆成两个等级。** 90+ 是较难达到的高分表现，不单独设置更高评价档，也不应让最高档评价只出现在评分表末端。

| 分数 | 评价档 |
|---:|---|
| 80–100 | S |
| 65–79 | A |
| 50–64 | B |
| 35–49 | C |
| 0–34 | D |

适用：制作质量评价、作品评价 rating、商业表现档位等所有需要离散评价等级的 0–100 分评分。若某个系统只用于连续数值计算、不展示等级，则保留连续分数，不强行添加等级。

90+ 可以用于描述“极高分/接近满分”，但不得因此生成 S+、SS、神作等额外评分档。作品评价与制作质量仍然分开计算。

## 2. 项目规模与预算

合同预算就是制作预算。仅选择委员会模式时，项目总投资规模 = 合同预算 × 2；承制模式不生成投资规模。

| 规模 | 合同预算/制作预算 | 委员会总投资规模 | 周期 | 总工作量 | 目标质量 |
|---|---:|---:|---:|---:|---:|
| 短篇 | 3,000万 | 6,000万 | 16周 | 1,800 | 62 |
| OVA | 2,000万 | 4,000万 | 12周 | 1,200 | 60 |
| TV | 20,000万 | 40,000万 | 52周 | 6,000 | 70 |
| 剧场版 | 30,000万 | 60,000万 | 72周 | 8,000 | 75 |

以上是游戏内项目梯度建议，需结合团队产能和现金流模拟，不应直接视为现实行业单项目报价。

## 4. 制作阶段

五阶段工作量建议分配：

| 阶段 | 工作量占比 | 能力权重 |
|---|---:|---|
| 脚本 | 10% | planning 70%、management 30% |
| 分镜 | 15% | direction 80%、planning 20% |
| 原画 | 35% | drawing 85%、direction 15% |
| 动画检查 | 25% | animation 70%、drawing 30% |
| 后期 | 15% | postproduction 85%、management 15% |

制作方针初始建议：

| 方针 | 工作效率 | 质量倾向 |
|---|---:|---:|
| 质量优先 | -10% | +10% |
| 均衡 | 0% | 0% |
| 进度优先 | +15% | -10% |

以上加成为初始提案，最终应由 #4 根据真实工作量模型校准；质量倾向不能突破 0–100 上限，也不能替代员工能力与阶段质量计算。

## 5. 员工状态与成长

| 参数 | 初始建议 |
|---|---:|
| 每周疲劳基础增长 | 4 |
| 每周休整恢复 | 8 |
| 加班额外疲劳 | 5 |
| 疲劳开始影响效率 | 60 |
| 疲劳明显影响效率 | 80 |
| 士气开始产生负面影响 | 30以下 |
| 高士气轻微加成 | 80以上 |
| 单周基础经验 | 1 |

成长应来自真实工作；临时员工不培养。疲劳除影响效率外，可以影响质量稳定性，但不宜在首版叠加过多惩罚。

## 6. 委员会与渠道

投资比例维持已确定规则：10%–100%，每次调整10个百分点。玩家非 BD 渠道分成比例等于自身投资比例；投资比例不影响制作工作量、质量上限、责任或决策权。

BD 适用所有企划：公司取得 BD 毛收入的初始 50%，其余 50% 作为综合成本口径，不得重复扣款。

非 BD 渠道潜力初始参考（0–100）：

| 渠道 | 普通适配 | 高度匹配 |
|---|---:|---:|
| 出版社 | 20–40 | 60–85 |
| 玩具 | 15–35 | 60–90 |
| 音乐 | 20–40 | 60–85 |
| 电视播出 | 30–50 | 65–90 |

渠道潜力表示企划与渠道的适配程度，不是收入保证。渠道收入规模应由渠道基础规模、企划适配、商业表现等共同决定。

无电视台成员时，委员会项目可购买电视播出服务：
- 费用建议：合同预算的 3%。
- 宣传效果建议：商业表现计算获得约 5% 的加成。
- 每个项目最多一次。

此项需验证是否会让购买服务成为无脑必选。

## 7. 商业表现与收入

商业表现为独立的 0–100 分，不直接等于制作质量。统一评价档位按第 1 节执行：

| 分数 | 商业档位 |
|---:|---|
| 80–100 | 大热 |
| 65–79 | 热门 |
| 50–64 | 普通 |
| 35–49 | 低迷 |
| 0–34 | 失败 |

BD 毛收入初始参考：

| 商业档位 | BD 毛收入参考 |
|---|---:|
| 失败 | 合同预算 × 0.1 |
| 低迷 | 合同预算 × 0.4 |
| 普通 | 合同预算 × 0.8 |
| 热门 | 合同预算 × 1.5 |
| 大热 | 合同预算 × 3.0 |

公司实际取得 BD 毛收入的 50%。委员会非 BD 渠道收入独立计算，再按玩家投资比例分配。爆款 ×5 是独立彩蛋，不纳入常规收入曲线。

## 10. 首轮经济模拟验收

至少模拟以下情境：
1. 开局前两年正常经营。
2. 普通承制项目。
3. 普通委员会项目。
4. 低质量项目。
5. 商业大热项目。
6. 100% 投资项目。
7. 破产边缘项目。

重点检查现金流、单项目利润、十年可完成作品数量、员工培养速度、承制与委员会收益差距。初始资金、工资、项目预算、制作周期和商业收入曲线必须联动校准。

## 11. 参数责任与落地纪律

- #4：阶段工作量、阶段能力权重、质量传递与制作方针。
- #6：企划规模与报价、委员会投资、渠道潜力、商业收入、声望与延期。
- #7：员工工资、疲劳、士气、成长与招聘相关参数。
- #8：长期成长、作品履历与十年结局评价。
- 总体负责人：跨模块经济模拟、路线收益、首局难度与十年节奏审查。

本文件的数值是统一的首轮参考基准。模块负责人可以在此范围内提出调整，但不得各自建立互相冲突的评分档位。任何将 80–89 与 90–100 拆成不同评价等级的设计，都需要先经总体负责人确认。
