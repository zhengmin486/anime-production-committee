# 四层数值锚点：无冲突执行基线

> 状态：仅汇总已由正式决策确认、且与 2026-11-25 四层数值锚点提案无冲突的规则边界。  
> 生效方式：本文件不创设新玩法、不冻结新的平衡参数；与 DECISION_LOG.md 不一致时，以 DECISION_LOG.md 为准。  
> 日期：2026-11-25

## 1. 时间与制作边界

| 项目 | 已确认口径 |
|---|---|
| 经营周期 | 520 周，即 10 年 |
| 时间步长 | 每次推进 1 周 |
| 标准 TV 集数范围 | 12–13 集 |
| 短篇集数范围 | 1–4 集 |
| OVA / 剧场版 | 1 集 |
| 制作结构 | 项目级公共制作 + 单集制作；单集固定六阶段 |
| 人周换算单位 | 1 人周 = 100 工作点；这是单位换算，不代表能力 50 员工必然每周产出 100 点 |
| 人员归属 | 核心员工每周只能归属一个项目；同周不得跨项目拆分或支援 |

**不得从本表推导：** TV 合同期限 52 周、36–44 周理想工期、短篇/长篇理想工期、能力 50 的基础产能。这些仍需 #63/#55 标定与正式确认。

## 5. 委员会与商业结算

| 项目 | 已确认口径 |
|---|---|
| 委员会总投资池 | 制作费 × 2；其中制作费占 50%，其余 50% 打包覆盖宣发、事务局、筹备及杂项 |
| 投资本金支付 | 项目开始时一次性支付玩家应承担的本金 |
| 委员会分配 | 先扣除适用且已约定的前置商业成本；玩家按投资比例取得净商业池，其他成员合计取得剩余份额；不采用本金优先返还 |
| 制作费与成本 | 制作费是制作公司收入，实际制作成本是制作公司费用；两者独立核算 |
| BD/DVD | 所有企划均可获得基础 BD/DVD 收入；收入始终归制作公司，不进入委员会商业收入池 |
| 委员会渠道成员 | 对应渠道开放，渠道手续费 0% |
| 外部代理 | 无对应成员时，声望≥100 或同类渠道合作≥1 次为 45%；声望≥190 或合作≥3 次为 40%；声望≥350 或合作≥5 次为 35%；取最高档位，合作次数按渠道类型独立累计 |
| 渠道关闭 | 两项代理开放条件均不满足时，渠道关闭、该窗口收入为 0 |
| 电视倍率 | 不播出 100%；普通播出 115%；电视台成员强力播出 125%；高级/黄金档 130% |
| 电视倍率适用范围 | 国内配信、玩具/周边、音乐、BD/DVD；不作用于海外发行及电视版权收入本身 |

DEC-COMM-001 的 100/190/350 外部代理声望门槛与 45%/40%/35% 费率继续有效；T0–T7 新档位不自动重映射这些阈值，调整须另行裁决。

承制项目的 BD/DVD 收入归制作公司；承制项目不参与其他五个常规商业窗口及委员会特殊商业分配。不得把 BD/DVD 收入写入委员会 Pro-rata 分配池。

## 6. 经济标定的正式目标边界

以下比例已在 DEC-ECON-001 中确认是**标准、顺利承制项目的标定目标**，不是每个项目的保证值：

| 指标 | 已确认目标 |
|---|---:|
| 直接制作成本 / 制作费 | 65%–75% |
| 制作毛利率 | 25%–35% |
| 扣除公司固定开支后的净现金增长 | 15%–25% |

委员会失败项目可能损失 30%–60% 投资本金；爆款目标回报可达到同规模承制路线净回报的 4–8 倍。这些同样是标定目标，不是收益保证。

以上比例不冻结标准 TV 制作费的绝对金额、薪资公式、外包价格或特定评级的商业回款。
