# 游戏设计总览（V1.0 目标）

> **状态说明（2026-11-24）：** 本文是旧 V1.0 目标玩法说明，保留作历史设计与迁移参考。其内容不一定覆盖当前已确认的新规则；冲突时以 [DECISION_LOG.md](DECISION_LOG.md) 和 [DOMAIN_ARCHITECTURE.md](DOMAIN_ARCHITECTURE.md) 为准。


> 本文是 V1.0 的整体玩法说明。旧版 v2 的按天推进、三工序、固定三报价等内容仅作为历史纵向切片保留，不再作为新玩法设计依据。当前实现进度见 [PROGRESS.md](PROGRESS.md)，具体规则以 [GAME_RULES.md](GAME_RULES.md)、[DATA_MODEL.md](DATA_MODEL.md) 和 [API.md](API.md) 为准。

## 1. 产品核心

玩家经营一家动画制作公司，在十年内持续寻找企划、组织制作、控制资金与风险，并通过作品表现积累公司声望和长期经营成果。

主要决策发生在项目选择、合作模式、阶段配置、人员与供应商选择、事件处理和项目结算等节点。时间推进采用周制，但不要求玩家每周重复安排所有人员；阶段配置在阶段开始时完成，阶段内自动执行。

设计目标是形成轻量、可复盘的经营策略循环，而不是完整模拟动画产业，也不是逐日微操。

## 2. 时间与经营循环

- 公司经营周期为十年，共 520 周。
- 时间以周为基本步长。工资、运营费用、项目工作、疲劳、士气、市场热度等时间相关变化统一挂接周结算。
- 公司在制作项目之间仍持续经营；空闲周仍需支付工资与运营成本。
- 公司一次只制作一部作品。作品交付并完成结算后，回到空闲经营窗口。
- 空闲期可以接取市场企划、等待下一周刷新、创建自定原创企划或处理员工提案；具体动作受状态和资金条件约束。
- 等待企划不是免费操作：推进空闲周会发生经营成本，并按规则刷新市场机会。

~~~text
新开公司
  ↓
空闲经营：市场四槽 / IP 上门 / 员工提案 / 自定原创
  ↓
选择企划、合作模式与投资比例
  ↓
阶段配置 → 周推进 → 事件处理
  ↓
阶段完成后重新配置下一阶段
  ↓
作品交付 → 项目结算 → 作品履历
  ↓
回到空闲经营，直至主动结束、破产或第 520 周
~~~

## 3. 企划来源与市场

### 3.1 市场企划

- 市场每次刷新固定四个企划，来源与规模分开生成，组合不重复。
- 至少两个企划可以立即承接；声望不足的高档企划仍展示，并明确标注解锁条件。
- 企划来源影响受众基础和商业预期，不直接进入制作质量计算。
- 企划规模提供不同合同预算（即制作预算）、工期、工作量和目标质量要求。委员会投资规模不作为独立企划规模参数生成。
- 市场热度影响相关题材的市场企划出现概率。热度只有大热、高、中、低四档，各题材独立变化，使用统一变化规则，不设置题材专属基础热度或题材间竞争。
- 市场热度按较长周期更新，不会每周剧烈波动；每次最多变化一档。玩家只看到当前档位，不看到变化方向或历史曲线。

### 3.2 IP 上门

- IP 上门是特殊市场企划，不是独立入口。
- 出现时直接占用市场四个企划槽之一，仍然保持每次四个企划。
- 市场热度影响 IP 上门出现概率；声望和历史作品成绩可作为准入条件。
- 首版不做额外弹窗、额外槽位或限时过期机制。

### 3.3 自定原创与员工提案

- 原创企划不进入普通市场。玩家主动创建与员工提案是两种不同发起方式。
- 玩家主动创建时可选择少数核心方向，其余企划参数由系统生成；需要具备企划能力的员工。
- 员工提案按周期概率触发，提案内容由员工形成，玩家只决定采纳或拒绝，不重新选择题材、规模等方案内容。
- 员工提案触发概率不受公司声望或市场热度影响；员工提案不占市场四槽，只展示一次，推进空闲周未采纳即消失，拒绝无经济惩罚。
- 两种原创发起方式均在正式立项时支付相同的固定前期开发费用；提案展示本身不扣款。
- 所有企划均可选择承制或制作委员会模式；原创企划仍必须采用委员会投资。选择委员会模式后，委员会投资规模按合同预算的 2 倍生成，公司承担 10%–100%，其他投资方自动补足剩余比例。100% 为公司独资。
- 原创前期开发费用独立于投资本金，不参与商业收益分成。

## 4. 合作模式与财务

### 4.1 承制（contract）

- 合同预算就是项目制作预算，按合同要求完成作品。
- 承制模式下合同预算在项目开工时作为制作资金入账；交付时按质量和履约情况结算扣罚。
- 承制不参与委员会成员招募及非 BD 渠道分成，不申请延期。
- 合同收益不受题材市场热度影响。

### 4.2 委员会投资（committee）

- 选择委员会模式时，项目投资规模按合同预算（即制作预算）的 2 倍生成；未选择委员会模式时不生成投资规模。
- 公司按整数百分比承担委员会投资，比例为 10%–100%；投资本金在开工时支付一次，其他投资方共同补足剩余投资。
- 合同预算始终就是项目制作预算；委员会投资规模与制作预算是分开的口径，不能把投资规模当作制作预算或额外合同收入。制作预算开工时并入公司统一现金池，不另设独立预算钱包。
- 委员会投资玩法包含两个操作维度：控制公司投资比例、拉入委员会成员开放渠道。一个成员对应一个渠道；成员加入委员会即开放对应渠道，但渠道开放与投资比例、投资金额没有数值绑定关系。
- 成员及其开放渠道在立项时固定，制作中不追加或更换；不记录其他成员的细分投资比例或渠道分配比例。
- 项目最多延期一次，需满足资格与资金条件，并承担延期费用和委员会压力；承制项目不允许延期。
- 公司商业收益按渠道规则结算，不采用简单的「总商业收入 × 公司投资比例」统一公式。

### 4.3 现金与成本

- 公司现金、项目账目分别记录；同一笔现金支出只扣一次。项目制作预算并入公司统一现金池，预算资金使用后继续由公司现有现金承担制作支出，不设置预算耗尽后停止制作或自动追加投资的机制。
- 工资、运营、制作、临时员工、外包、事件、延期、违约、前期开发和发行服务等成本按类别记录。制作经营亏损可能发生于承制和委员会项目，与委员会投资本金亏损分开核算；强制支出无法支付时触发破产结算、游戏失败。
- 已支付的投资、外包、事件或延期费用在项目结算时只汇总，不重复扣除。
- 项目结算后更新公司资金；公司关闭后即使项目回款，也不能解除关闭状态。
- 详细付款时点、破产预检和终局优先级见 [GAME_RULES.md](GAME_RULES.md)。

## 5. 五阶段制作

制作阶段顺序固定：

1. 企划与脚本（script）
2. 分镜与演出（storyboard）
3. 原画制作（key_animation）
4. 动画与作画检查（animation_check）
5. 摄影与后期（postproduction）

每阶段开始时，玩家配置人员、内部工作方案、外包和制作方针。阶段开始后进入 active，常规配置锁定；阶段完成后进入下一阶段的 ready 状态，玩家可以重新配置。

阶段之间存在有限质量传递：前阶段成果会影响后阶段，但不能完全决定后阶段质量，也不能被后期无限覆盖。阶段内按周推进，工作量、阶段质量、人员经验、疲劳和士气由核心规则计算。

## 6. 人员与外部资源

- 团队采用固定核心员工加项目临时招募。
- 员工有六项专业能力；当前能力与潜力分离，天赋类型由种子生成，潜力线索逐步揭示。
- 经验来自实际参与的相关专业工作；跨专业成长慢于本专业，有个人成长上限。
- 员工有疲劳与士气，影响效率，严重时影响质量。系统提供离职风险预警，不进行随机离职。
- 不做自由加点、复杂培训树、转职升职、个人剧情或员工随机离职。
- 临时员工与外包供应商是两类资源。主动外包和应急外包遵守供应商专业、产能、质量、速度、报价与可靠性规则；应急外包不能直接挑选最优供应商。

## 7. 制作事件

- 事件依附当前项目，不做独立公司级事件。
- 事件包含负面异常与正面机会，来源结合项目表现触发和随机触发。
- 每周最多触发一个事件；同一时间最多一个待处理事件。触发后暂停后续周推进，处理完才能继续。
- 事件效果分为即时、阶段和项目持续三类；不追溯修改已结算阶段，不设置跨项目永久效果。
- 普通事件与固定重大事件并存。重大事件可有前置条件、预兆和跨阶段影响，同一重大事件在同一项目最多触发一次。
- 事件选项由事件性质决定。确定代价必须明确展示，主要风险可展示等级或预期，不要求公开精确概率。
- 事件不能修改合同目标或合同条件，不能绕过财务、供应商、员工和终局规则。应急外包复用供应商系统。
- 重大事件进入作品履历；普通事件按需要汇总，不逐条堆积。

## 8. 作品评价与商业渠道

### 8.1 制作评价

- 五阶段分别产出阶段质量，最终制作质量为五阶段综合结果，范围 0–100。
- 第一版按作品规模选择阶段权重模板，企划来源暂不影响阶段权重；常规模板权重由前期向后期递减。
- 作品档次为 S/A/B/C/D，使用固定分数线，不按同期作品排名。
- 企划适配度是辅助评价因素，影响小于制作质量；由系统根据企划定位与最终成品自动判断，不由玩家直接调整，也不反向修改最终制作质量。
- 重大事故单独影响最终评价，不简单并入阶段质量平均值；核心环节事故完全放弃处理时可能导致评价崩盘或作品失败。
- 不向玩家展示大量作画、剧情、音乐、演出等细分分数；不做独立奖项和业界评选系统。

### 8.2 商业表现

- 制作质量与商业成绩独立评价，作品卖得好不直接提高制作质量或作品档次。
- 商业收入按渠道分别计算，再汇总。
- BD 是所有企划的基础收入渠道，承制与委员会统一采用同一分配：初始按 BD 毛收入的 50% 计入公司收入，另外 50% 作为 BD 综合成本；该比例是可调整的游戏平衡参数，不代表现实行业统一费率，但成本比例必须大于 0，BD 不能全部成为公司收入。实现时可将毛收入增加后扣除 50% 成本，也可直接按 0.5 计算公司所得；两者结果必须一致，不能重复扣成本。
- 选择委员会模式后，玩家可通过立项时固定的委员会成员拓展渠道；一个成员对应一个渠道，成员加入即开放对应渠道。委员会非 BD 渠道收入按玩家投资比例分配。承制模式不拉入委员会成员，不通过委员会成员机制拓展渠道。
- 玩具等渠道使用独立商业潜力值；潜力与制作质量分开，实际收入结合作品表现与市场情况。
- 网络播放版权和海外发行属于发行商渠道。电视台股东可提供电视播出渠道；没有电视台股东时，委员会项目可购买电视播出服务，产生发行成本并带来宣传提升。
- 第一版不做广告与品牌赞助。渠道收入在作品完成后统一结算，不分批入账。

## 9. 声望与长期经营反馈

- 公司声望同时具有数值与等级：初始 100，最低 0，不设数值上限；不自然衰减，只由经营行为和项目结果改变。
- 等级按固定数值区间升降，不按动态排名；具体阈值和称号后续统一设计。
- 声望变化不随机，每次变化记录原因、数值并保留历史。
- 声望影响企划档次与质量分布、外部委托档次和报价、招募候选人质量分布、供应商解锁、原创企划其他投资方的投资规模，以及媒体关注和初期曝光。
- 声望不改变企划刷新数量、候选人数，不影响员工提案触发概率；永久解锁资源不会因声望下降而收回。
- 声望不直接影响员工专业能力、疲劳、士气、制作效率、阶段质量或委员会压力。委员会压力与公司声望分开。
- 市场热度与声望影响不同：热度影响题材供给和非合同商业收益；声望影响机会档次、准入与公司影响力。

## 10. 作品历史、竞争与结局

- 作品历史永久记录作品名称、类型、题材、制作人员快照、综合质量、作品档次、商业成绩、结算结果和系列关联。
- 同一 IP 可有续作、前传、外传；上一部作品影响最大，更早作品提供较弱的长期系列积累。前作表现影响商业基础，不影响续作制作质量和作品评价；不做系列市场疲劳。
- 竞争公司只在作品结算时参与比较，具有少量固定档案和基础属性；不模拟其日常经营与动态兴衰。
- 不做独立年度经营报告。
- 公司经营结束后生成简洁经营总结，展示累计作品、代表作、累计商业收入、最终资金、声望、团队成长及正负特殊评价。
- 结局档次采用综合评价，累计表现为主、最终状态为辅。破产优先判定经营失败；十年期满与主动结束使用同一评价标准。
- 突出单项成就可突破基础结局档次，并获得相应特殊评价；特殊评价不分等级，可同时存在正面与负面。负面评价不直接降低已判定结局档次。
- 员工展示最终状态、能力成长和代表作品经历，不生成复杂个人命运故事。

## 11. 明确不做

首版不做：多项目并行、复杂动态竞争公司、观众群体模拟、题材间竞争、广告赞助、独立媒体系统、独立奖项系统、年度经营报告、复杂剧情分支、员工个人剧情、随机离职、复杂培训与自由加点、跨项目永久事件效果、事件直接改合同、系列市场疲劳。

具体参数、概率、阈值和内容清单留在执行阶段细化，不因未定数值而反复重开已经确认的规则方向。
