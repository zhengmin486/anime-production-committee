# 对照审查成果

本目录存放第二阶段成果：独立研究报告完成后，对照项目既有设计、历史研究、审计、规则、代码契约和决策记录形成的综合判断。

每项成果应链接对应的 `../independent/<主题>/` 报告，并明确记录：

- 旧方案中建议保留的内容及依据；
- 建议修订、废弃或重新验证的内容及依据；
- 独立研究中需要修正的判断；
- 新方案带来的体验、系统关系、实现成本和风险；
- 需要项目负责人决定的重大问题。

历史研究的对照流程不替代当前决策纪律。已确认规则如需修改，必须按 DECISION_LOG.md 的“变更已确认决策”流程提交证据、影响与迁移方案，未经负责人批准不得覆盖。
