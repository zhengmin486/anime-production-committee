## 模块目标

实现玩家在经营窗口中选择项目的经营决策：市场提供差异化企划，玩家判断来源、规模、合作方式与投资比例；项目开始后，企划数据与委员会成员/渠道候选按冻结契约交给核心结算。

## 已确认规则（不可自行改写）

1. 经营窗口展示固定 4 个市场企划；刷新重新生成 4 个，企划不会自动过期；等待刷新照常支付周成本。
2. 至少 2 个企划可立即承接；声望不足的项目仍可展示并标记锁定及解锁条件，锁定项不能占满 4 个位置。
3. 企划来源与规模独立：
   - 来源：漫改、轻改、游戏改、原创。
   - 规模：OVA、短篇、TV、剧场版。
   - 不要求所有来源与规模组合均可生成。
4. 原创企划必须走委员会投资；选择承制应被拒绝并说明原因。
5. 合作模式按项目选择：承制或委员会投资。委员会最低投资比例 10%，最高 100%，整数百分比；其余份额由合作方自动补足，不做逐个投资人谈判。
6. 投资比例只影响出资和商业收益分配，不赋予额外决策权；投资本金只扣一次，不先回收本金。
7. 制作合同预算属于项目总投资用途，不是总投资之外的额外收入；合同收入与商业分成不得重复入账；超支由自有资金承担，不改变投资比例。
8. 委员会延期最多一次，按既有契约结算费用和项目内压力；承制不能延期。委员会压力与公司声望分开。
9. 制作质量与商业表现分开计算；来源受众基础和商业预期系数职责不同，不合并为同一个因素。
10. 市场热度影响企划供给、IP 上门概率和非合同商业收益，不影响合同收益。市场热度的状态存储与题材标识属于跨系统契约缺口，未经负责人确认不得自行新增字段。

## v4 自主原创准入补充

- 自主原创的创建资格由独立公司声望与资金/开发费条件决定；企划槽与委员会会议室不垄断资格，不建设创作资料库等设施也仍可依靠主创经验和常规市场信息开展企划（DEC-COMPANY-002）。
- `create_custom_offer(name, source, scale, style)` 只执行创建资格、非危机、自定槽可用和开发费守卫；不得增加“必须有企划能力员工”的隐性资格门槛。
- 创建原创企划不等于正式立项。`start_work` 仍须校验企划存在、原创仅委员会模式、投资与资金、委员会/渠道等既有立项条件；原创选择承制仍拒绝。
- 企划能力员工是否属于正式立项的执行资源、是否占用产能或需要指定人员，正式决策尚不足以唯一确定，保留待确认。确认前不得把它当资格门槛，也不得自行新增资源消耗规则。
- 自主原创声望阈值、开发费与资金门槛均待数值标定；本模块不得自行冻结数值。

## 模块负责人的交付内容

1. **市场生成与刷新**：4 个企划的生成、锁定展示、可承接保底、等待与刷新行为。
2. **企划数据**：来源、规模、风险收益差异和卡片所需可读信息；组合参数集中配置，待定值标注 `TODO(待定)`。
3. **合作选择**：承制/委员会路线校验、原创限制、投资比例校验及开始项目所需数据。
4. **委员会输入**：提供报价与委员会成员候选；渠道开放、分账、BD 保底 50%、`channel_breakdown` 精确对账和电视服务购买由核心规则层负责。
5. **延期输入**：提供委员会路线延期所需参数/建议，遵守最多一次和承制不可延期，不自行另建压力或财务规则。
6. **对账与验收材料**：至少提供 10% 与 100% 投资样例、承制样例、原创承制拒绝、超支、等待刷新等可手算记录。
7. **规则文档**：提案和最终确认参数同步 `docs/GAME_RULES.md`；字段/接口变更由负责人统一维护契约文档。

## 明确不做

- 不做委员会投票权、席位、成员政治或逐个投资人谈判。
- 不做宣传发行部门、年番、动态市场或企划自动过期。
- 不把市场热度、公司声望、委员会压力混成同一个变量。
- 不实现渠道分账核心逻辑，不改合同账目口径。
- 不自行修改共享核心文件或冻结契约字段。

## 交付与验收

- [ ] 4 个企划的风险收益组合有实际区别，信息足以支持玩家选择。
- [ ] 至少 2 个企划可立即承接；锁定企划显示条件且不占满 4 槽。
- [ ] 来源与规模独立，原创承制被拒绝。
- [ ] 自主原创创建资格由独立声望与资金条件决定，会议室/企划槽不垄断；创建资格与正式立项资格分开校验。
- [ ] 企划能力员工作为执行资源的必要性仍标待确认，未被实现成隐性资格门槛。
- [ ] 10% / 100% 投资本金计算正确且只扣一次。
- [ ] 等待刷新扣周成本，刷新后仍为 4 个且不囤积旧企划。
- [ ] 委员会延期最多一次，压力与公司声望独立。
- [ ] 对账表可手算，合同收入、投资支出、制作成本、商业分成无重复计入。
- [ ] `npm run test:native`、`npm run test:wasm` 提供真实输出；未执行项如实标注。
