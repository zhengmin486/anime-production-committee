## 2. 我们要做一款什么游戏

《动画制作委员会》是一款以开罗游戏为主要设计参考的轻量动画制作公司经营模拟游戏。玩家经营一家动画制作公司，在十年的经营周期内，通过承接动画企划、组织作品制作、参与制作委员会、建立产业合作关系，逐渐成长为拥有优秀人才、代表作品和行业影响力的动画公司。

本作不是现实动画产业链的完整沙盘，不是逐镜头制作模拟，也不是单纯的委员会投资模拟器。玩家应通过有限但有分量的经营决策，组织人才与产业资源，推动作品完成，在机会、风险和意外中建立自己的动画事业。

**核心定位：玩家经营的是动画制作公司；作品是经营活动的核心目标；制作委员会是围绕具体作品连接投资方与产业资源的合作机制。**

### 2.1 产业背景

产业设定为当代、配信主导的动画产业环境，而不是简单复刻 2005 年前后的円盤时代。配信、商品化、海外发行、电视播出和 BD/DVD 等窗口共同构成商业环境；各窗口的具体权利、开放条件、收入归属与结算方式以当前决策登记册为准。

现实动画产业是设计素材，不是必须完整复刻的对象。产业机制必须服务于玩家经营与作品目标，不能为了模拟现实而堆叠无意义的细节。

### 2.2 趣味假设（可证伪）

> 这款游戏好玩的核心是：玩家愿意为“下一部押什么”反复权衡，而不是为“这一周怎么排”反复操作。

出现以下任一情况，都说明核心体验需要重新审视，而不能只靠调数值掩盖：

- 玩家在第 3 部作品之后，开始用同一套配置机械推进，不再关注项目与作品差异；
- 玩家在十年结束时，回忆不起任何一部作品或任何一次重要押注；
- 最优策略退化为“永远接最简单的小活”或“永远选择同一种合作模式”，没有值得判断的经营时刻。

首版试玩应观察这些信号，并结合玩家访谈、行为记录和策略模拟验证。试玩人数、时长和判定阈值属于验证方案，不是运行时规则。

### 2.3 目标玩家与节奏基线

- **平台与形式**：浏览器端、单人经营模拟。
- **目标玩家**：玩过开罗系经营模拟、对动画产业有兴趣，但不要求具备行业知识的玩家。
- **单局总时长目标**：约 6–10 小时。
- **经营周期**：十年、520 周，以周为统一时间步。
- **作品交付量目标**：十年约 12–18 部，作为节奏与产能设计的目标区间。

上述时长和作品数量是产品节奏基线，应通过实际试玩与数值模拟校验；它们不应被误读为对玩家的硬性任务，也不能反过来扭曲当前已确认的制作流程与规则。

## 3. 公司、作品与制作委员会

### 3.1 公司：玩家长期经营的主体

玩家经营的是动画制作公司，不是委员会，也不是某一部作品。

公司长期积累资金、核心员工与人才储备、设施与长期资产、公司声望、作品履历以及投资方和发行商等合作关系。公司可以并行经营多部作品；员工、现金和外部产能属于公司共享资源。某部作品结束，不会让公司重置。

公司成长的意义不是让数字单纯变大，而是让玩家逐渐获得以前无法承担的项目、人才、合作机会和经营选择。**成长必须改变玩家能做的事，而不只是放大旧数值。**

### 3.2 作品：经营活动的核心目标与项目载体

作品是玩家最直接追求的目标，也是公司组织制作和商业活动的载体。

每部作品有独立的企划定位、规模、集数、制作计划、进度、质量、风险、商业安排和最终结果。作品制作由项目级公共制作与单集制作构成；单集采用六阶段流程，工作项按依赖关系和最低交付门槛推进，各集进度可以不同步。

作品不是一条等待填满的进度条。玩家应该能感受到制作瓶颈、阶段差异、质量取舍、团队表现和突发变化，并理解经营决策如何影响最终成果。

### 3.3 制作委员会：围绕具体作品建立的合作机制

制作委员会不是玩家长期经营的公司，也不是全局共享的资源池。它围绕采用委员会合作模式的具体作品建立，用于组织投资方与产业伙伴，为作品提供资金、商业渠道与产业资源。

委员会成员的价值不只是出资，还包括其掌握的渠道、权利与产业资源。成员类型、渠道开放条件、投资比例、分账、项目生命周期等具体规则，以当前 DECISION_LOG.md 为准。

委员会跟随对应作品成立。作品完结并完成项目结算后，委员会停止活动；曾经合作过的对象及合作结果可以沉淀为公司的长期关系资产。委员会是项目级机制，公司的经营生命周期则持续十年。

### 3.4 承制与委员会：两种商业合作身份

承制和委员会不是简单的难度档位，而是两种不同的商业合作方式：

- **承制**：公司以受托制作方身份承接项目，获得合同制作费，并按当前规则取得相应的 BD/DVD 收入；不参与其他常规商业窗口及委员会特殊商业分配。
- **委员会**：公司参与项目投资并组织制作，承担相应制作经营风险与投资商业风险，并按已确认规则参与商业分配。

两种模式的资金来源、成本归属、收入范围和风险结构必须严格遵循当前决策登记册。不得从旧版愿景或历史实验中恢复已被替换的经济口径。

### 3.5 三者形成经营闭环

公司持续积累资金、人才、声望和合作关系；公司通过承接企划或发起原创企划组织作品制作；作品交付后形成商业结果、作品评价与合作结果；这些结果再影响公司下一轮经营选择。

三者定位必须始终清楚：**公司是经营主体，作品是核心目标，委员会是围绕作品连接投资与产业资源的机制。** 不能把游戏做成只经营委员会的投资模拟器，也不能让作品退化成普通项目管理任务。

## 4. 核心循环与经营节奏

### 4.1 三层循环

| 层级 | 时间尺度 | 玩家主要行为 | 必须提供的反馈 |
|---|---|---|---|
| 瞬时 | 数秒至数分钟 | 查看局势、调整安排、处理项目事件、决定是否推进一周 | 让玩家知道发生了什么、为什么发生、有哪些选择 |
| 单部作品 | 数周至数十周 | 选择企划、决定合作模式、配置人员与方针、组织制作并完成交付 | 让玩家看到最初的经营决策如何变成作品结果 |
| 长线经营 | 十年 | 积累资金与人才、提升公司地位、建立产业关系、选择重要押注 | 让玩家感受到公司逐渐获得过去无法拥有的能力与机会 |

多项目并行应产生资源竞争和经营取舍，但不能让玩家被重复的清单维护和无意义微操淹没。当前项目级事件与周推进仲裁规则以 DECISION_LOG.md 为准，不采用旧版“全局每周只有一个待处理事件”的设计。

### 4.2 玩家追求的三个层次

- **短期：做好眼前的作品。** 选择值得投入的企划，决定合作模式，组织团队和资源，控制成本、进度与风险，处理制作过程中的问题，最终交付一部令人满意的作品。
- **中期：建立有能力的公司。** 积累资金、培养员工、改善工作环境、提升声望、拓展合作关系，并逐渐具备并行经营多部作品、承担更大项目风险的能力。
- **长期：建立自己的动画事业。** 在十年周期中形成公司的特色：核心人才、代表作品、稳定的产业关系、系列 IP，以及能够持续经营的商业模式。

### 4.3 战略承诺：经营故事的重要来源

十年经营中，玩家应有少量重要的、具有长期后果的战略承诺。已确认的设计目标是十年约 3–4 次，方向包括押注原创、押注系列、押注重要档期等。

战略承诺应当有真实代价，承诺当下付出资源，未来逐步兑现；一旦作出，不应成为可以无成本随意撤销的普通配置。它的价值在于创造玩家能记住的经营故事，例如某次原创押注失败、某部作品成功后建立系列，或一次重要档期改变公司后续发展。

该设计属于已确认的产品方向。具体承诺类型、触发条件、成本、兑现方式和实现阶段，应在对应系统设计中细化，并与当前规则和工程契约对齐；本文不自行补造具体命令或数值。

## 5. 核心乐趣：设计支柱与优先级

以下五条支柱有优先级。设计发生冲突时，优先级较高的支柱优先；如果某项设计长期无法兼容高优先级目标，应调整或重做系统，而不是不断添加例外。

| 优先级 | 设计支柱 | 设计要求 |
|---:|---|---|
| 1 | **有代价的取舍** | 资源有限，每个选择都意味着放弃另一个机会；避免没有代价的“两全”方案 |
| 2 | **公司成长改变可做的事** | 成长必须带来新项目、新人才、新合作或新经营能力，而不是只放大旧数字 |
| 3 | **作品有过程感** | 玩家能识别瓶颈与风险，看到决策如何转化为制作结果；不能只剩纯进度条 |
| 4 | **人才是长期资产** | 员工应有专业、经验、潜力与状态，玩家应能记住团队成员及其贡献 |
| 5 | **可理解但不可完全预测的随机** | 随机结果可解释、可复现，波动不能压过玩家决策 |

冲突裁决示例：培养员工需要让他参与项目，控制成本可能要求调整人员安排。不能为了保留某一员工的成长机会而取消真实经营取舍；同时，员工成长也不能被设计成只在固定岗位上才有意义。系统应让玩家理解取舍及其后果。

随机性应制造意外、惊喜、危机和值得复盘的故事，而不是用不可解释的骰子结果否定玩家决策。

## 6. 玩家操作与自动化边界

玩家主要负责选择项目、决定合作模式与委员会构成、制定项目方针、分配公司共享资源，并在重要节点作出经营决策。

已经配置的持续方针和资源计划应尽可能自动执行。玩家不应每周重复安排所有员工或重新填写所有选项。周推进是统一的周期模拟与结算入口，但不是所有操作的通用生效按钮；即时操作、下一周执行和延迟生效的边界遵循 DECISION_LOG.md 及对应系统契约。

设计目标不是消除所有操作，而是让操作有意义：玩家可以主动干预真正重要的经营问题，但不需要反复执行没有新信息、没有取舍的机械步骤。

## 7. 风格与参考方向

开罗游戏是本项目的主体参考。借鉴的是经营模拟的设计方式，而不是必须采用像素美术：

- 系统容易理解，玩家能快速掌握基本规则；
- 决策数量有限，但选择会产生真实影响；
- 经营结果及时、直观且有反馈；
- 员工、设施、项目和资源之间有清晰联系；
- 成长、解锁和长期目标能持续驱动玩家；
- 随机变化让每局经历不同；
- 玩家可以快速理解局势，不需要行业知识。

其他作品可以为特定机制提供参考，但不能让整体设计失去统一性。现实动画产业是设计素材，不是必须完整复刻的对象。

## 8. 明确不做的方向

| 不希望的方向 | 原因 |
|---|---|
| 工作流或项目管理软件 | 玩家应该经营公司，而不是维护任务清单 |
| 现实动画产业 ERP | 过多商业细节会稀释核心经营乐趣 |
| 逐镜头、逐帧制作模拟 | 操作粒度过细，玩家负担过高 |
| 纯委员会投资模拟器 | 委员会服务于具体作品，不是游戏全部 |
| 单纯数值增长游戏 | 数值增长必须改变实际经营能力或未来机会 |
| 无意义的每周微操 | 重复操作不等于经营深度 |
| 纯随机游戏 | 随机不能压过玩家决策和长期经营 |
| 彼此割裂的功能集合 | 所有系统都应共同服务于公司经营与作品目标 |
| 只看终局现金的成败判定 | 十年经营的意义是“建立了什么”，不只是账户余额 |
| 为复刻现实而堆叠细节 | 现实机制必须转化为清晰、有趣的经营选择 |

## 9. 失败状态与风险反馈

失败必须有清晰形状，否则系统容易一味朝“更安全”方向调整。

- **项目层面**：延期、质量不达标、商业失败等，应产生与原因相匹配的损失、声望或合作影响；单个项目失败不应自动等于公司破产。
- **经营层面**：资金风险应提前、清楚地呈现，让玩家理解固定成本、已承诺支出和现金余量；但当前版本不提供资金不足后的额外自救周。刚性支出预检不足时整周回滚并直接破产。
- **公司层面**：破产是公司级终局，应能追溯到玩家此前可见的经营选择与风险累积，而不是隐藏规则造成的意外惩罚。

限时危机周、融资自救和削减承诺等机制仅作为未来更新候选。若后续评估，必须重新走规则变更与平衡验证，不得覆盖当前 DEC-FIN-002/003。

## 10. 复杂度预算

首版可交互概念预算为 **12 个**。新增可交互概念不能仅以“再加一个功能”的方式不断叠加；超出预算时，应说明其体验价值，并提出替换或合并现有概念的方案。

当前概念预算基线：

1. 现金池与统一周结算；
2. 企划与规模档；
3. 合作模式（承制 / 委员会）；
4. 投资比例与分账；
5. 委员会成员与渠道；
6. 单集六阶段与工作项；
7. 制作方针；
8. 员工分配与磨合；
9. 外包与供应商；
10. 事件；
11. 声望；
12. 战略承诺。

这是一项产品复杂度约束，不意味着所有概念都必须在同一里程碑实现，也不意味着每个概念只能对应一个数据实体或界面。实现时应避免通过拆分命名、增加子菜单等方式规避复杂度审查。

## 11. 设计与实现的判断标准

设计或实现任何系统时，依次回答：

1. 它是否增加了有意义的经营选择？
2. 它是否让玩家的决策产生真实、可理解的影响？
3. 它是否增强了作品制作过程的变化和反馈？
4. 它是否让员工、公司或产业关系产生实际价值？
5. 它是否为长期经营提供了新的动力？
6. 它带来的体验价值是否值得增加的复杂度？

系统即使技术上实现完整，如果没有增加经营乐趣，也不应仅因为已经投入开发就被保留。为了方便实现而做的简化，也要判断是否限制了核心体验。

如果某项设计看似与已确认规则冲突，应先区分是表达方式、系统实现还是规则本身的问题。任何要改变已确认规则的方案，都必须提交明确的变更提案，说明原规则、证据、影响、替代方案和推荐意见，等待负责人裁决；不能通过修改愿景文档绕过决策流程。

## 12. 成品成功的判断

不以系统数量、代码规模或文档数量衡量。目标成品应当做到：

| 标准 | 验证方式 |
|---|---|
| 玩家能理解公司、作品、委员会三者关系 | 首次游玩后，玩家能说明三者的区别与联系 |
| 公司资源有限，需要作有意义的选择 | 试玩中出现多个可行但不能同时承担的机会，玩家会权衡 |
| 不同员工、合作模式和经营策略产生不同结果 | 固定策略模拟与试玩中，各路线呈现可解释的差异 |
| 每部作品的制作过程有变化 | 玩家能说出某部作品卡在哪里、为什么，以及自己做过什么决策 |
| 委员会连接具体作品的投资与产业资源 | 玩家能解释引入某个成员或渠道的目的 |
| 公司成长改变未来机会与制作能力 | 玩家在经营后期能承担早期无法承担的项目或选择 |
| 随机性产生可理解、可复盘的经历 | 试玩后能讲出具体事件、原因及应对结果 |
| 玩家愿意继续经营 | 十年结束后，玩家仍有继续开新局或追求不同经营路线的意愿 |

希望玩家在十年结束时感受到：

> 这家公司是我一点点经营起来的。  
> 这些作品是我组织团队制作出来的。  
> 这些员工陪伴公司走过了很多年。  
> 我经历过失败，也抓住过机会。  
> 十年过去，我建立了一家真正属于自己的动画公司。
