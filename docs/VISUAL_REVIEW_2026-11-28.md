## 一、目标视觉规范草案

| 项目 | 规范草案 | 理由 |
| --- | --- | --- |
| 画布 | 保持 8:7；逻辑像素场景建议 448×448，所有关键内容位于约 5% 安全边距内 | 与现有页面比例一致，减少裁切和导航跳动 |
| 视角 | 正面、略俯视的二维像素场景；家具以脚点落地，不混用强 3D 透视 | 现有 2dPig / Antea 资源均以此类表现为主 |
| 像素尺度 | 原资源按最近邻整数倍缩放；同一场景内家具不单独放大以填充空白 | 避免 pixel size 忽大忽小 |
| 人物 | 统一为 2dPig 人物脚点基准；站立人物高约场景 9%–12%，遮挡顺序按脚点 y 坐标 | 与现有 5 名角色比例一致，便于招聘后扩展 |
| 层次 | 固定为房间 → 后墙家具 → 后排工位 → 人物 → 前景家具 → 审查标记 | 防止桌脚悬空、家具穿人、地毯误遮挡 |
| 色彩 | 米白墙、浅木地板、青蓝窗景、深青结构色；珊瑚/陶土仅作强调 | 延续明亮、低压力的现有方向 |
| 对比 | 业务文字不依赖画面；画面内标识使用深色底或浅色底承载，保证 4.5:1 文本对比 | 右侧是纯净展示，左侧承担真实操作 |
| UI | 继续使用现有侧栏与抽屉；Lucide 图标、系统字体、纸面卡片不改为像素字体 | 避免美术重制扩大为 UI 架构改造 |
| 动效 | 默认静态；仅允许轻微状态提示，不添加持续闪烁或镜头运动 | 降低干扰与性能成本 |
| 资源接入 | 单件 PNG 或 sprite sheet + 场景配置坐标；业务组件不直接写死家具坐标 | 支持后续独立替换 |

### 交互热点结论

交互模型已确认：四个主场景的画面内部均不放置选项、按钮或可点击热点，所有选项只出现在左侧边栏。右侧画面负责环境、对象与状态展示；业务操作继续通过现有侧栏动作和抽屉展开。

因此不实现场景内双入口，不改变侧栏-only 的键盘导航、焦点返回和可访问性行为。视觉审查中提到的空间对应仅作为后续美术调整参考，不转化为画面内操作层。

### 复用、组合、AI 与自制的适用条件

- **直接复用**：仅用于许可明确、风格与透视一致的 2dPig / Antea 单件资源。
- **组合**：适合办公室样板；用统一房间底、脚点坐标和 z 序控制，不把不同来源按相同像素尺寸硬拼。
- **AI 辅助**：只适合 mood board、构图草图和自有元素的概念探索；进入正式资源前必须确认生成服务条款、AI 标识政策和修改/分发权。不能把 AI 高清海报混入像素场景。
- **自制**：适合规则化地板、墙窗、图表、铭牌、简单道具和热点配置；成本可控且权属清晰。复杂角色动画和大幅背景优先复用或委托。
- **成本口径**：本轮不按素材数量计价。一个场景的改造工时主要由“背景/家具拆分、坐标与遮挡调整、浏览器验收”组成；整图替换表面便宜，但后续不可局部维护，返工成本更高。

## 六、发行与市场人物修正

### 结论

按“还原成之前的最终版模样，如果眼镜男不好做删除操作就删除红衣女”的要求，市场场景先完整恢复上一版最终图，再仅移除右下角红衣女。光头眼镜男、圆桌、椅子和地板保持原有位置与层次。

### 实现方式

- 以 Git 中的上一版最终 `DistributionMarket.svg` 为基线，不沿用未获确认的光头男删除方案。
- 校准人物实际精灵边界：黑衣红衣女使用 2dPig 表集中 `x=21, y=128, width=20, height=32` 的水平翻转精灵；光头眼镜男使用 `x=39, y=96, width=16, height=32` 的水平翻转精灵。
- 首次移除阶段仅修改红衣女独占的 260 个像素，当时光头眼镜男遮挡区改动数为 0；后续另清理其头顶残留的 18 个鞋脚像素。
- 修复首次删除造成的背景损坏：按原图墙面、木饰面、踢脚线和显示器左边缘的结构还原占位区域，不使用邻近像素拖拽或模糊填补。修复后仍仅这 260 个像素发生变化，范围保持在 `(166,157)` 至 `(182,178)`。
- 进一步清理右侧光头男头顶残留的 18 个鞋脚像素，按 2dPig 原始精灵逐像素恢复；该补丁范围为 `(174,174)` 至 `(179,178)`，左侧光头男与画面其他区域不变。
- 市场画面重新内嵌为 256×224 PNG，SVG 尺寸、页面布局、侧栏动作和业务状态不变。
- 场景继续保持单层背景，不引入临时人物前景层。

### 验证结果

- `npm run typecheck`：通过。
- `PrototypeApp.test.tsx`：14 个测试全部通过。
- `npm run build`：通过。
- 实际页面：市场场景仅 1 张背景图，画面内控件数量为 0；数字键 4 可进入市场。
- 控制台：重新加载后未发现 `error` 或 `warn`。
- 当前证据：`docs/evidence/visual-review/market-red-removal-final-page.png`、`market-red-removal-final.png`、`market-right-bald-head-fixed.png`。

## 七、建议的后续顺序

1. 保留当前已确认的办公室完成版，不继续推进分层样板。
